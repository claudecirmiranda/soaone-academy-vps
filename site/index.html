O problema

A demo tem três caixas. A produção tem quatro camadas.

Um LLM cru esquece o contexto, alucina dados, quebra a lógica de negócio e obedece a quem escrever o texto mais convincente. O curso ensina a construir o que fica ao redor dele.

Expectativa
Usuário→API do LLM→Resposta

Esquece contexto · inventa política · vulnerável a prompt injection · conta da API sem teto

Realidade de produção
Usuário→Filtros inbound→Orquestrador · RAG · memória→LLM→Validadores outbound→Resposta

Regra no texto é pedido. Trava em código é lei.

Perguntas

Antes de começar

Preciso saber Python?

Os laboratórios usam Python, mas os conceitos valem para qualquer stack. Saber ler código e já ter chamado uma API REST é suficiente.

O curso depende de um provedor de IA específico?

Não. A arquitetura é neutra de fornecedor; os exemplos mostram como trocar de modelo sem mudar as camadas de defesa.

É gratuito mesmo?

Sim. E-book, aulas, laboratórios, lives e certificado não custam nada e não pedem cartão. O cadastro com e-mail é opcional e serve para salvar o progresso e avisar das aulas novas.

Por quanto tempo tenho acesso?

Sem prazo. O conteúdo fica aberto e recebe atualizações quando modelos e APIs mudam.

Tem certificado?

Sim, gratuito, emitido quando você publica o projeto final: um agente de atendimento com os 13 guardrails ativos.
